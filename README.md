# svg-to-cutcontour-pdf

https://forresto.github.io/svg-to-cutcontour-pdf/index.html

Need a pdf with named spot colors and don't want to open a heavy app? This utility helps my Cuttle.xyz to Roland VersaWorks workflow. (VersaSTUDIO BN2-20A sticker print and cut at Aalto FabLab.)

## Usage

Open `index.html` in a browser, then drop, choose, or paste an SVG. Hairline strokes of the chosen color (default `#FF00FF`, 0.3 pt or thinner) are recolored to a `CutContour` spot color and exported as a PDF that VersaWorks reads as cut lines. The preview marks cut paths with marching ants, the export is verified before download, and nothing leaves your browser.
